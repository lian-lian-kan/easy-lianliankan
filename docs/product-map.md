# 产品交互地图（2026-09-18，与代码同步维护）

> 本文档是界面信息架构的单一事实源：层级、页面清单、动线与闭环。任何页面/入口改动须先改这里再改代码；
> 逐条闭环由探针锁定（page_probe / panels_probe / start_screen_probe）。

## 1. 层级模型（L0–L4，交互的骨架）

| 层 | 内容 | 规则 |
|---|---|---|
| L0 外层 | 落地页(web) → 加载壳 → **首页**(标题页) | 每次进游戏必经；首页走 open_modal 暂停语义 |
| L1 主场景 | **棋盘** | 唯一玩法主场；关页/关弹窗都回到它 |
| L2 一级页 | 导航 7 键：主页(=回棋盘) / 🎮玩法 / 🗺️旅程 / 📖图鉴 / 🎁有礼 / 🎉活动 / 🛍️小铺 | 一级页互相直达（导航互跳）；手机宽度决定 7 键上限 |
| L2.5 二级页 | 📊数据 / 📋任务★ / 🏆成就★ / 🌳攀登树 | 不占导航；从首页快捷区、设置、或一级页入口进入 |
| L3 弹窗 | 暂停 / 设置 / 数据迁移 / 关卡工坊 / 引导 / 大树增益 / 复活 | 低频操作与强上下文操作用弹窗，不做页面 |
| L4 浮层 | 消息横幅 / 成就通知 / 求助老公 / 樱花瓣 | 只反馈，不承载导航 |

**层级原则**：玩法（棋盘）→ 进度（导航页）→ 记录（二级页）→ 操作（弹窗）→ 反馈（浮层），
从上到下频率递减。新增内容先问放哪一层，再动手。

## 3. 首页（标题页）与主动线

```
落地页 → 加载 → 首页 ──▶ ▶开始游戏 ──▶ 棋盘（续关）
                 ├─▶ 快捷 2×3：玩法大厅 / 旅程 / 有礼 / 数据 / 任务 / 成就
棋盘 ─ HUD ⏸暂停 ──▶ 继续循环 / 重开 / 返回第1关 / 🌸回到首页 / 退出特殊
设置（⚙️）──▶ 数据 / 成就 / 大树 / 迁移 / 工坊 + 5 个一级页入口
```

- 新玩家：首页 → 开始游戏 → 引导弹窗（onboarding 挪到开局时刻）→ 棋盘。
- 老玩家：首页 → 开始游戏（或快捷入口去别的页面）。

## 4. 闭环清单（每个动机都有去处、每个去处都有归途）

| 闭环 | 动线 | 状态 |
|---|---|---|
| 玩法闭环 | 首页/导航 → 玩法大厅 → 选玩法 → 棋盘 → 结算 → 再来 | ✅ 已有 |
| 签到闭环 | 有礼 → 签到领🌸 → 钱包 → 小铺消费 | ✅ 已有 |

| **成就闭环** | 对局达成 → 通知浮层 → 成就页看全列表 → 设置/首页可达 | ★ 本轮（弹窗→页面） |

| **肉鸽无尽** | 无尽过关 → 轮间三选一增益（复用树增益面板） → 更大一轮 | ★ 本轮 |

| 回家闭环 | 任何页面 ‹ 返回 → 棋盘；棋盘 ⏸ → 🌸回到首页 → 首页 | ✅ 已有 |

## 6. 历史决策存档

- 导航 7 键是 390px 宽度极限，新增页面一律走二级页（首页快捷/设置/一级页入口），不再加导航键。
- 弹窗 vs 页面：强上下文（暂停/迁移/工坊）留弹窗；陈列型内容（成就/任务）页面化。
- 「主页」导航键语义 = 关页回棋盘；「首页」= 标题页（暂停面板🌸回到首页）。两个「家」并存是有意的：
  棋盘是玩法主场（家），标题页是会话入口（门户）。
